김도영 | Data Analyst Portfolio

데이터의 기준을 정의하고, SQL로 사용자 행동의 변화를 설명하는 데이터 분석가 김도영입니다.

코드잇 스프린트 데이터 분석 15기를 수료하며 SQL과 Python을 활용한 데이터 전처리, 탐색적 데이터 분석(EDA), 사용자 행동 분석 및 시각화 프로젝트를 수행했습니다.

단순히 수치를 집계하는 데 그치지 않고, 분석 기준을 명확하게 설정하고 결과를 서비스 운영 관점의 인사이트로 연결하는 데 집중했습니다.

기술 스택

SQL: BigQuery, MySQL

Python: pandas, 데이터 전처리, EDA, 시각화

데이터 분석 환경: dbt, Jupyter Notebook, Google Colab

협업 및 문서화: GitHub, Notion

01. 익명투표 서비스 질문 확산 및 생명주기 분석

6인 팀 프로젝트 | 담당: 질문 확산·생명주기 분석

초기 학교 도달 수와 후반 답변 유지율을 기준으로 질문을 4개 유형으로 분류

빠른 확산 질문과 느린 확산 질문의 장기 유지형 비율이 각각 51.7%, 51.1%로 유사함을 확인

질문의 확산 속도와 반응 지속성을 별도 지표로 관리할 필요성을 제안

사용 기술: BigQuery SQL, dbt
