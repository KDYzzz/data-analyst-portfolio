### SQL 분석 코드

**1. 질문 확산 및 생명주기 분석 — BigQuery SQL**

- 파일: `doyoung_eda3_question_lifecycle.sql`
- 실제 답변(`answer_status = 'A'`)을 기준으로 질문별 첫 답변일을 Day 0으로 정의
- Day 0~14 답변 추이, 초기 학교 도달 수, 후기 답변 유지율을 계산
- 확산 속도와 유지율을 교차하여 질문을 네 가지 유형으로 분류
- 이 파일은 분석 과정의 주요 SQL을 정리한 것으로, 포트폴리오의 1,536개 질문 선정에 사용한 관찰 기간 제한 조건은 별도로 포함되어 있지 않음

**2. 사용자 데이터 전처리 — MySQL 계열 SQL**

- 파일: `doyoung_user_preprocessing.sql`
- `user_properties`를 기준으로 `accounts_user`를 LEFT JOIN
- 사용자 230,819명을 유지하면서 매칭 여부를 구분
- 결측 및 의미가 불명확한 변수는 임의 변경하지 않고 원본 유지
- 전체·고유 사용자 수와 매칭·미매칭 수를 검증하는 쿼리 포함

※ 두 SQL은 팀 프로젝트에서 직접 작성한 작업물을 포트폴리오 목적으로 공개한 코드입니다. 원본 데이터는 포함되어 있지 않습니다.
