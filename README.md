# 김도영 | Data Analyst Portfolio

**데이터의 기준을 정의하고, SQL로 사용자 행동의 변화를 설명하는 데이터 분석가**

코드잇 스프린트 데이터 분석 15기를 수료하며 SQL과 Python을 활용한 데이터 전처리, 탐색적 데이터 분석(EDA), 시각화 및 사용자 행동 분석을 경험했습니다.

분석을 시작하기 전에 **무엇을 측정할 것인지, 어떤 기준으로 비교할 것인지**를 명확히 정의하는 데 집중합니다.

| SQL | BigQuery SQL, MySQL |

## 주요 프로젝트

### 01. 익명투표 서비스 — 질문 확산 및 생명주기 분석

**6인 팀 프로젝트 | 담당: 질문 확산·생명주기 분석**

**분석 목적**

빠르게 여러 학교에 도달한 질문이 시간이 지난 뒤에도 답변을 유지하는지 확인하고, 질문의 확산 속도와 반응 지속성을 구분해 분석했습니다.

**내가 수행한 작업**
- 질문·답변·사용자·학교 데이터를 연결해 분석용 데이터 구성
- 질문별 첫 실제 답변일을 Day 0으로 정의하고 Day 0~14 반응 비교
- Day 3 학교 도달 수와 후기 답변 유지율을 기준으로 질문 4유형 분류
- BigQuery SQL을 활용한 집계 및 분석 결과 정리

**팀 분석 결과**

팀 발표 분석에서는 빠른 확산 질문과 느린 확산 질문의 장기 유지형 비율이 각각 51.7%, 51.1%로 나타났습니다. 이를 바탕으로 초기 확산과 후기 반응을 별도 지표로 관리할 필요성을 제안했습니다.

*참고: 공개 SQL은 주요 분석 로직을 정리한 코드이며, 발표에 사용한 1,536개 질문의 관찰 기간 제한 조건은 포함되어 있지 않습니다.*

**사용 기술:** BigQuery SQL, dbt

### 02. 공유오피스 무료체험 — 사용자 행동 및 결제 전환 분석

**6인 팀 프로젝트 | 담당: 전처리·초기 행동 구간·시계열 기준 모델**

**분석 목적**

무료체험 사용자의 방문 행동을 분석하고, 방문 이후 결제로 이어지는 과정의 특징을 파악했습니다.

**내가 수행한 작업**
- 신청·방문·출입·결제 데이터의 품질 점검 및 전처리
- 사용자 단위 분석 데이터 구성과 결제 여부 기준 검토
- 무료체험 초기 D0~D2 행동 구간 설정
- 일별 방문자 수 집계 및 Moving Average 기준 모델 작성

**팀 분석 결과**

무료체험의 방문 단계보다 방문 이후 결제 전환 단계에서 개선 필요성이 발견되었으며, 서로 다른 날짜에 반복 방문하는 행동이 결제와 관련된 주요 특징으로 나타났습니다.

**사용 기술:** Python, pandas, 시계열 분석

### 03. 서울 공공자전거 따릉이 — 이용량 및 이용 패턴 분석

**6인 팀 프로젝트 | 담당: 데이터 병합·전처리·이용 추이 분석**

**분석 목적**

연도별 공공자전거 이용량 변화를 파악하고, 이용 패턴과 서비스 운영 개선 방향을 살펴봤습니다.

**내가 수행한 작업**

- 연도별 데이터 병합 및 전처리
- 월별 이용량 집계와 연도별 추이 비교 및 시각화

**팀 분석 결과**

이용자 특성, 강수, 서비스 운영 관점에서 이용량 변화와 개선 가능성을 분석했습니다.

**사용 기술:** Python, pandas, 데이터 시각화

### 04. 채용 플랫폼 — 유령·방치 공고 분석

채용공고의 신선도와 사용자 반응을 기준으로 관리가 필요한 공고를 구분하고, 구직자 경험을 개선할 방안을 검토했습니다.
